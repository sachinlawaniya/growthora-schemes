# Growthora Government Schemes Portal

A dedicated, high-performance web platform built for Indian MSMEs, startups, and expanding businesses to find, evaluate, and apply for central and state government funding schemes, capital subsidies, and collateral-free credit programs.

## 🚀 Features

- **Interactive 3-Step Scheme Finder**: Multi-dimensional matching algorithm across support types, business categories, and funding amounts with real-time counters.
- **Dedicated Scheme Landing Pages**: Full-fidelity landing pages for key government schemes:
  - **PMEGP Scheme**: Prime Minister's Employment Generation Programme
  - **Mudra Loan (PMMY)**: Shishu, Kishore & Tarun Categories
  - **Startup India (SISFS)**: Seed Fund Scheme
  - **CGTMSE**: Credit Guarantee Fund Trust for Micro and Small Enterprises
  - **PMFME Scheme**: PM Formalisation of Micro Food Processing Enterprises
  - **TUFS**: Amended Technology Upgradation Fund Scheme
  - **CLCSS**: Credit Linked Capital Subsidy Scheme
  - **Stand-Up India Scheme**: For Women & SC/ST Entrepreneurs
  - **MSME ZED Scheme**: Zero Defect Zero Effect Certification
- **Dynamic Semantic URL Routing**: `/schemes/<scheme-slug>` with automatic browser history synchronization (`pushState` / `popstate`).
- **3D Isometric Depth & Textures**: Layered shadow cards, 3D perspective grids, floating holographic badges, and smooth micro-animations.
- **Growthora Brand Design System**: Tailored Deep Navy (`#0D1836`) and Vibrant Orange (`#F97316`) theme with glassmorphism and modern typography.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS v3.4**
- **Lucide React Icons**

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/sachinlawaniya/growthora-schemes.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
